# Reproduire les expériences

## Environnement
Enregistrer les versions Python, scikit-learn, NumPy et pandas. Fixer les seeds du générateur et des modèles. Écrire les paramètres, les métriques et le hash des données dans un rapport. Des versions différentes peuvent modifier les résultats.

## Données synthétiques
Une simulation vérifie le fonctionnement du pipeline et facilite une démonstration publique. Ses scores ne prouvent pas une performance sur des clients réels. Le générateur encode ses propres hypothèses et peut rendre la tâche artificiellement facile.
